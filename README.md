# SadOne Stickers · 手账贴纸库

<p align="center"><b>240 枚手账贴纸 · 14 个分类 · 全部原图抠切 · 透明底 PNG</b><br>
丝带标题 · 便签卡 · 和纸胶带 · 邮票 · 涂鸦图标 —— 从手绘素材图逐枚切出，不是画的</p>

**SadOne Stickers** 是一套手账风贴纸素材库：把两张手绘素材图（~500 个手绘元素）用计算机视觉自动切片——连通域检测、投影分割、洪泛保纸白、白底转透明——**每一个都保持原画笔触**，零重绘。

## 用法

贴纸是标准透明底 PNG，直接拖进设计软件 / 手帐 App / 网页都行：

```html
<img src="stickers/ribbon/ribbon_001.png" width="180">
```

- 白底已转透明（洪泛判定：只有贴纸外部的白透明，纸卡内部的纸白保留）
- 边缘 1px 高斯羽化，无白边毛刺
- 原始分辨率 150-300px，网页/文档场景清晰

## 切片管线（可复现）

```bash
python3 extract.py     # 连通域 + 投影分割 + 洪泛alpha → stickers_raw/
python3 classify.py    # 行聚类归类 → stickers/ 分类目录
python3 gen_site.py    # 生成预览站 → docs/
```
